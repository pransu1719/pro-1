// 01 — Overview

📌 About The Project

Yeh ek console-based Python program hai jo user ko do powerful tools deta hai — ek beautiful star pattern generate karna aur ek range ke numbers ko even/odd classify karna. Program ek loop mein chalta hai aur tab tak kaam karta hai jab tak user exit na kare.

// 02 — Features

⚡ Key Features

⭐

Star Pattern

User ki marzi ke rows mein centered star pattern print karta hai.

🔢

Number Analyzer

Start se end tak har number ko Even ya Odd batata hai.

🔁

Loop Menu

Baar baar menu dikhata hai jab tak user khud exit na kare.

🛡️

Invalid Input

Galat choice pe "wrong choice" message deta hai program crash hue bina.
